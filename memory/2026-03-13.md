### cron 任务长期静默失败（约40小时）
- **根本原因**：所有 cron 任务用了 `fast-pool` isolated agent，该 agent 无 auth key（auth-profiles.json 只有 qwen/minimax），ak/self provider 均失败
- **中间尝试**：改 agentId 为 main 但仍是 isolated sessionTarget → 同样无法找到 auth key

- **最终修复**：彻底放弃 OpenClaw cron delivery 机制，改用**系统 crontab** + shell 脚本 + curl 直发 TG

### 教训
- OpenClaw isolated cron job 必须确认 agent auth-profiles.json 有可用 key，否则静默失败
- sessionTarget=main + systemEvent 只是注入消息，不保证实际执行工具调用
- **最可靠方式：系统 crontab + shell 脚本 + curl 直发 TG**，不依赖任何 LLM session
